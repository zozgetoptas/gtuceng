



SORU 5: MATRIX IŞLEMLERI
------------------------
3x3 matris için:
- Transpose'unu hesapla (satırları sütun yap)
- Diagonal elemanların toplamını bul
- Matrisin determinantını hesapla



SORU 7: POINTER + ARRAY
-----------------------
int *p = arr; kulllanarak array'i işle.
*(p+i) syntaxı ile:
- En büyük elemanı bul
- Elemanları ters çevir
- Çift sayıları say

SORU 8: DOSYA + STRUCT + FILTER
--------------------------------
Araba bilgileri dosyasından oku (brand model year price).
Struct kullan.
2020'den sonra üretilen ve 100.000'den düşük fiyatlı arabaları filtreleyip yeni dosyaya yaz.

SORU 9: 2D ARRAY + FUNCTION
----------------------------
Function yazı:
int count_greater(int **arr, int rows, int cols, int value)
Value'dan büyük eleman sayını dön.
