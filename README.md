# GTU CENG Course Archive / GTU CENG Ders Arşivi

This repository contains assignments, lab work, exam preparations, and practice programs for computer engineering courses.
Bu depo, bilgisayar mühendisliği dersleri kapsamında hazırlanmış ödev, laboratuvar, sınav ve pratik çalışmalarını içerir.

## Contents / İçerik

### `cse101&107`

C programming fundamentals and related coursework:
C programlama temelleri ve ilgili ders çalışmaları:

- `assignments/` - Assignments / Ödevler
- `final/` - Final exam preparation and practice files / Final sınavı hazırlıkları ve pratik dosyaları
- `labworks/` - Lab work / Laboratuvar çalışmaları
- `midterm/` - Midterm exam preparation and practice questions / Vize hazırlıkları ve pratik soruları
- `prelabs/` - Pre-lab exercises / Ön laboratuvar çalışmaları
- `reports/` - Course reports / Ders raporları

### `cse102&108`

Coursework related to C programming and data structures:
C programlama ve veri yapılarıyla ilgili ders çalışmaları:

- `final/` - Final exam practice / Final sınavı pratikleri
- `labs/` - Lab work / Laboratuvar çalışmaları
- `quizzes/` - Quiz solutions / Quiz çözümleri

### `eng151&152`


- `152questions.pdf` - Example questions to study / Çalışmak için örnek sorular
- `science&technology.pdf` - Notes / Notlar

For programs that read input files, make sure the required `.txt` files are in the program's working directory.
Dosya girişi kullanan programlarda, ilgili `.txt` dosyalarının programın çalıştırıldığı dizinde bulunduğundan emin olun.

## Note / Not

This repository is maintained as a personal course archive. Some files may be drafts, experiments, or practice exercises.
Bu depo kişisel ders çalışma arşivi olarak kullanılmaktadır. Dosyaların bazıları deneme, taslak veya pratik amaçlı olabilir.
